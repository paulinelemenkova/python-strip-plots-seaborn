# Strip Plots with Python and Seaborn

Python/Seaborn scripts drawing categorical strip (jittered scatter) subplots of geomorphometric data for the Mariana and Philippine trenches. Reusable scientific-plotting example.

## Scripts

- `strip_subplot_phil.py`
- `strip_subplots_mar.py`

## Data

- `Tab-GeomorphPhil.csv`
- `Tab-Morph.csv`

## Requirements

Python 3 with `matplotlib`, `numpy`, `pandas`, `seaborn`.

```
pip install matplotlib numpy pandas seaborn
```
